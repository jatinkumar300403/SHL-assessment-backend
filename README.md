# SHL Assessment Conversational Agent

This repository contains the backend and simple UI for the SHL product catalog AI agent.

It is built using:
- **FastAPI** for the backend framework.
- **ChromaDB & SentenceTransformers** for RAG (Retrieval-Augmented Generation).
- **Google Gemini** for LLM orchestration and strict schema compliance.
- **Docker** for deployment on Hugging Face Spaces.
